プライバシーポリシー

制定日: 2026年10月22日

DeskCalendar（以下「本アプリ」）は、Andante（以下「開発者」）が開発・提供する Windows 用ウィジェットです。 本ポリシーは、本アプリが Google アカウントのデータをどのように扱うかを説明するものです。

1. アクセスするデータ

本アプリは、利用者が Google アカウントでログインして許可した場合に限り、次のデータにアクセスします。

  • Google カレンダーのカレンダー一覧（名前、色、既定の通知、タイムゾーン）
  • 予定（タイトル、日時、場所、説明、繰り返し、通知、色、ゲストと出欠、ビデオ会議のリンクなど）

使用する権限は Google Calendar API の https://www.googleapis.com/auth/calendar（カレンダーの表示と編集）のみです。メール、ドライブ、連絡先などその他のデータにはアクセスしません。Google アカウントのパスワードを本アプリが受け取ることはありません（ログインは Google のページで行われます）。

2. データの利用目的

取得したデータは、次の目的にのみ使用します。

  • 予定を利用者のパソコンのデスクトップに表示すること
  • 利用者が設定した通知の時刻に、Windows の通知で予定を知らせること
  • 利用者の操作（予定の追加・変更・削除、招待への出欠）を Google カレンダーに反映すること

広告、分析、機械学習、利用者の追跡など、上記以外の目的には使用しません。

3. データの保存

データは利用者のパソコン内（%APPDATA%\DeskCalendar）にのみ保存されます。ログイン情報（トークン）と予定のキャッシュは、Windows のデータ保護機能（DPAPI）で暗号化し、そのパソコンのその Windows ユーザーだけが読める形で保存します。

4. 第三者への提供・送信

本アプリの通信先は Google のサーバー（accounts.google.com、googleapis.com）のみで、通信は暗号化（HTTPS）されています。開発者のサーバーやその他の第三者にデータを送信・提供・販売することはありません。開発者が利用者の予定を閲覧することもできません。

なお、利用者が予定にゲストを追加して「招待メールを送る」を選んだ場合、招待メールは Google カレンダーの機能によって Google から送信されます。

5. Google API サービスのユーザーデータに関するポリシーの遵守

本アプリによる Google API から受け取った情報の使用および他のアプリへの転送は、制限付き使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに準拠します。

DeskCalendar's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

6. データの削除とアクセスの取り消し

  • 本アプリのメニューの「ログアウト」で、Google 側の許可を取り消し、パソコン内のログイン情報とキャッシュを削除できます。
  • Google アカウントのサードパーティ接続から、いつでも本アプリのアクセスを取り消せます。
  • 本アプリを削除する場合は、%APPDATA%\DeskCalendar フォルダを削除すると、パソコン内のデータがすべて消えます。

7. ポリシーの変更

本ポリシーを変更する場合は、このページで告知します。
