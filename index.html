DeskCalendar

Google カレンダーをデスクトップに表示する Windows 用ウィジェット

できること

  • Google カレンダーの予定を、デスクトップ（他のウィンドウの後ろ）に常に表示
  • 月のカレンダーと、選んだ日からの予定一覧
  • 予定の追加・変更・削除（繰り返し・通知・色・ゲスト・Google Meet など）
  • 予定の通知を Windows の通知で表示
  • 招待された予定への出欠の返信

Google アカウントのデータについて

DeskCalendar は、利用者が Google アカウントでログインして許可した場合に限り、Google Calendar API を使って利用者のカレンダーと予定を読み書きします。データは利用者のパソコン内にのみ暗号化して保存され、開発者や第三者に送信されることはありません。

詳しくは プライバシーポリシー をご覧ください。
